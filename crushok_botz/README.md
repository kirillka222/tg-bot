# Crushok Bot — бот "Кружок"

Точный аналог механики @crushok_robot: платный просмотр кружков (списание
монет), лайки/дизлайки со счётчиками, платное раскрытие автора, "кружки
пользователя", закреплённые (приоритетные) профили и тестовая загрузка
контента админом.

## Как это выглядит для пользователя

1. `/start` → приветствие → меню
2. Жмёт «🎥 Смотреть кружки» → бот пишет «🔎 Ищу кружок...»
3. Через **5 секунд** (настраивается) показывается кружок, монеты списываются,
   под видео появляется «-1 🪙 Баланс: N»
4. Под кружком кнопки:
   - 👍 N / 👎 M — лайк/дизлайк, счётчики обновляются на кнопке в реальном времени
   - 🔒 Узнать автора — платно (по умолчанию 5 монет), после оплаты показывает
     имя/username автора; повторный показ уже бесплатный (запоминается)
   - 🔑 Кружки пользователя — показывает другой кружок этого же автора,
     если он у него есть
   - »» Следующий кружок — показывает следующий сразу, без повторной
     5-секундной задержки (задержка только при первом запуске просмотра)

## Как ты (админ) добавляешь контент для теста

Пока нет реальных пользователей, лента будет пустая — это нормально,
показывать нечего. Чтобы наполнить её для теста:

```
/seed
```
→ бот попросит прислать кружок (видео-заметку) → отправляешь любое своё
видео-сообщение → бот создаёт **тестовый профиль** с этим кружком, который
будет показываться реальным пользователям в общей ленте (в том числе тебе
самому, если зайдёшь с другого аккаунта).

Можно вызвать `/seed` несколько раз — добавится несколько тестовых кружков.

## Как закрепить конкретного пользователя, чтобы его кружки показывались первыми

```
/pin <user_id> [приоритет]
/unpin <user_id>
```

Например: `/pin -1 20` — сделает тестовый профиль с id `-1` (полученный из
`/seed`) самым первым в ленте у всех. Чем выше число — тем выше приоритет.
`/unpin` сбрасывает приоритет в 0 (обычная случайная выдача).

## Настройки экономики (`.env`)

```
START_COINS=15          # монет при регистрации
VIEW_COST=1              # стоимость одного просмотра
REVEAL_AUTHOR_COST=5     # стоимость раскрытия автора
SEARCH_DELAY_SECONDS=5   # задержка "поиска" перед первым показом
```

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
# впиши BOT_TOKEN от @BotFather и свой ADMIN_IDS
python main.py
```

## Остальные разделы меню (без изменений с прошлой версии)

- **🎭 Смотреть анкеты** — отдельная от кружков лента анкет (фото/имя/возраст/о себе)
- **👤 Профиль** — баланс, статус кружков/анкеты, количество реакций, рефералы
- **📤 Загрузить** — записать ещё один кружок (можно несколько) или заполнить анкету
- **🎯 Задания** — авто-начисление монет (первый кружок, анкета, 5 просмотров, друг)
- **⭐ Магазин** — трата монет на бусты/VIP (см. ограничение ниже)

## Важные ограничения текущей версии

- Покупки в магазине списывают монеты, но сам эффект (буст показов,
  VIP-бейдж) не применяется автоматически — это транзакция-заглушка.
  Реализовать несложно поверх уже готового поля `priority` в БД: например,
  при покупке `boost_24h` вызывать `db.set_priority(user_id, 5)` на 24 часа
  (понадобится отдельное поле `boost_until` и периодическая проверка/сброс).
- «Кружки пользователя» показывает только **один** дополнительный кружок за
  клик (не листалку по всем). Если нужна полноценная листалка — легко
  расширить хендлер `cb_more_from_owner`.
- Нет модерации контента — стоит добавить кнопку «Пожаловаться» перед
  публичным запуском.
- 5-секундная задержка блокирующая (через `asyncio.sleep`) — при большом
  количестве одновременных пользователей это нормально для aiogram
  (не блокирует других), но если нужно — можно заменить на индикатор
  "печатает..." вместо текстового сообщения.
